# Pizza Amici homepage

Static GitHub Pages site with the homepage and six placeholder destination pages.

## Files
- `index.html` — homepage
- `site-layout.css` and `site-layout.js` — shared header, responsive menu, and footer
- `pizza-food-truck/`, `pasta-food-truck/`, `inspiration/`, `success-stories/`, `about-us/`, `contact/` — placeholder pages with a header, banner, blank content area, and footer

The local pages are intended as placeholders until their individual content is added.
